Biblioteca de video por nivel

Configuración

Necesitas una API key de Google Drive y el ID de la carpeta que contiene las subcarpetas de nivel (Principiante, Intermedio, Avanzado). Esto se guarda solo en este navegador.

¿Cómo consigo esto?
  1. En Google Cloud Console, crea un proyecto (o usa uno existente) y habilita la Google Drive API.
  2. En "Credenciales", crea una API key. Si vas a subir esta página a un sitio público, restríngela por dominio (HTTP referrer) para que nadie más la use.
  3. En Google Drive, comparte la carpeta principal como "Cualquier persona con el enlace puede ver". El permiso se hereda a las subcarpetas y videos de adentro, así que no hace falta compartir cada video por separado.
  4. Copia el ID de la carpeta: es la parte final de su URL, después de /folders/.
